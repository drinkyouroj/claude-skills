## Rules (apply to all slides)

- Always use the cover's job_id as the style reference.
- Never describe the scene from scratch — only describe the new element + reference the cover.
- Footer is identical on every slide.
- Headlines use editorial serif italic. Body text matches the medium (handwritten ink on journals, printed text on cards).
- Salmon `#DA7756` is the only accent color allowed.
