# Visual Prompts Pack

Plug-and-play prompts for the actor + product scene. Pick the one that fits the product, then fill in the bracketed bits.

All prompts are designed for `nano_banana_2` (Nano Banana Pro), aspect ratio `9:16`, resolution `2k`.

Always pass two reference images: the actor (Higgsfield job_id) and the product (uploaded media_id or job_id).

---

## 1. Bathroom mirror selfie (default for beauty, skincare, grooming)

```
The exact actor from reference image 1 standing in front of a
bathroom mirror, holding the exact product from reference image 2 up
to the camera with one hand, phone in the other hand. Soft warm
bathroom light. Slight steam from a recent shower in the
background. Casual, real, slightly imperfect framing. UGC selfie
style. 9:16 vertical, photorealistic.
```

---

## Negative prompt to append (use on every generation)

```
NOT: studio lighting, professional commercial, watermarks, text
overlays, logos other than the product's own, cropped face, blurry
product, multiple products, animated style, cartoon, anime, vector
art, plastic skin, over-saturated colors.
```

## Picking the right one

| Product type | Default scene |
|---|---|
| Skincare, makeup, grooming | 1. Bathroom mirror |
| Food, drinks, supplements | 2. Kitchen counter |
| Books, gadgets, niche | 3. Bedroom |
| Software, courses, B2B | 4. Home office |
| Parenting, on-the-go | 5. Car |
| Fitness, athletic | 6. Gym |
| Travel gear | 7. Outdoor walk |
| Mail-order anything | 8. Unboxing |
| Soft goods, candles | 9. Couch |
| Pet, garden, outdoor | 10. Backyard |

Default if unsure: kitchen counter. It works for almost everything
and reads as authentic.
