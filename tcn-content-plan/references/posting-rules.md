# TCN Posting Rules — Reference

## Platform Windows

| Platform | When to post |
|---|---|
| Substack Notes | Weekdays: 3–10 PM ET. Weekend: 8–11 PM ET only. |
| X (Twitter) | Anytime — no window restriction. |
| LinkedIn | Weekday afternoons preferred. No hard rule. |
| Flagship article | Friday AM — unrestricted. |
| Paid ("thinking behind the thinking") note | Wednesday, no specific window. |

**Hard restriction**: Never post Substack Notes or engage in public comments Tuesday–Thursday 8 AM–12 PM ET. This window is protected for the audience's morning reading time.

---

## Weekly Cadence

### Week 1 (Days 1–7)
- **Notes per day**: 1–2
- **Engagement**: 3–5 comments on Tier 1 accounts + 1 restack with added commentary
- **Weekend**: 1 Note only (bridge to next week's flagship)
- **Day 7 rule**: Bridge Note only (8–11 PM ET). Weekly review day — check tracking doc before posting.

### Week 2+ (Days 8–30)
- **Notes per day**: 3
- **Engagement**: 8 comments on Tier 1 accounts + 2 restacks with added commentary (not bare restacks — each restack must include one sentence of original analysis)

---

## Note Timing (Week 2+)

Standard posting slots for 3 Notes:
- **Note 1**: 3–5 PM ET
- **Note 2**: 6–7 PM ET
- **Note 3**: 8–10 PM ET

Flagship days shift this: Notes post after the flagship is live (typically mid-afternoon onward).

## Flagship Day Structure

A **flagship day** is when a major Substack article publishes. This is typically Friday, but check the monthly plan to confirm.

Flagship day has more moving parts than a standard day:

### Pre-publish (before article goes live)
1. Humanize pass — read draft against `workspace/core/anti-ai-writing-style.md`
2. Fix any sourcing issues flagged in the `flagship_prep` frontmatter block
3. Fact-check any claims added since the last fact-check pass

### Morning (alongside publish)
- **Substack article**: publish via Substack dashboard
- **X thread**: post all 10 posts as a thread; first post = hook; last post = article link

### Afternoon
- **LinkedIn repost**: 300–400 words, professional register, all figures cited, ends with link

### Evening (3–10 PM)
- **Note 1 (3–5 PM)**: Article Tease — one sharp claim from the piece + link. Post-publish only.
- **Note 2 (6–7 PM)**: Operator Observation or Primary Source Drop — fresh content that deepens the piece without repeating it
- **Note 3 (8–10 PM)**: Primary Source Drop or Contested Claim — different source or angle from the flagship

### X Thread Structure (10 posts)

The thread should walk the flagship's argument signal by signal, with each post self-contained:
- **Post 1**: Hook — the sharpest single fact or the most counterintuitive claim
- **Posts 2–8**: One signal or data point per post; each stands alone
- **Post 9**: The GDP/stakes line — why this matters at scale
- **Post 10**: Transition + article link ("Full analysis: [link]")

No post should summarize the piece. The thread fragments the argument so reading the thread still leaves the reader wanting the full piece.

### LinkedIn Repost Guidelines

- Professional register — no newsletter voice, no first-person analytical asides
- Cite every figure with its source (don't write "a study found")
- No CTA language ("subscribe," "check this out," etc.)
- End with the article link as the final line
- 300–400 words; cut the last paragraph if it runs long

---

## X Standalone Rules

- Post anytime — no window restriction
- No CTA of any kind — no link to article, no subscribe prompt, no "more on this in my newsletter"
- Self-contained: ≤50 words, readable without clicking anything
- 2–3 options per standalone, with a recommendation specifying when to use each option
- On flagship days, replace the standalone with the 10-post thread

## Engagement Targets

### Tier 1 Comment Targets (Week 2+)
Post comments on 8 accounts from the following categories. Match account to today's topic:

**Macro/monetary policy beat**: Lyn Alden, Luke Gromen (FFTT), Adam Tooze (Chartbook)
**Energy/infrastructure beat**: Doomberg, David Roberts (Volts), Bricks & Bytes authors
**Trade/economics beat**: Isabella Weber (UMass), Oren Cass, Matt Stoller
**AI/tech beat**: Packy McCormick (Not Boring), Ben Thompson (Stratechery)
**Fed/monetary beat**: Nick Timiraos (WSJ), Greg Ip (WSJ), Tim Duy (Bloomberg)

For each comment:
- Name the specific data point or frame from today's content that adds to their post
- The comment should teach the reader something they couldn't get from the original post
- Do not generic-comment ("great analysis") — add a specific analytical layer

### Restack Guidelines
- Find 2 Notes making a claim that today's content directly speaks to
- The ideal restack candidate is a Note making the consensus view that today's Contested Claim or Primary Source Drop challenges
- Add exactly one sentence of original analysis before restacking — the receipt that complements or complicates their claim
- Do not restack without adding commentary

## Paid Tier Note ("Thinking Behind the Thinking")

Published Wednesday, ~500–600 words. Backstage analytical note for paying subscribers.

Series label format (first line of content, before any heading):
```
*Process note — analytical backstage for [linked title](URL)*
```

Covers: what changed in the author's analysis during research, corrections made, analytical moves that didn't survive contact with the primary sources, what the published piece couldn't include.

Voice: first-person, confessional but precise. Not a summary of the article — it assumes the reader has read the article and wants to see behind it.

## Day 7 Weekly Review Checklist

Before posting the Day 7 bridge Note, run:
- Which Notes from Days 1–6 earned restacks? From who?
- Which 2 topics generated the most response?
- Which format pulled the most engagement?
- Cross-reference any new subscriber timestamps against Note publish times
- Update the tracking doc before posting
